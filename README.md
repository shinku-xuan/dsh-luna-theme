# dsh-luna-theme

> 借鉴 [Luna-Chat](https://gitee.com/ciallo0d00/luna-chat) 视觉语言的 **DeepSeek Harness（DSH）换肤插件**，桌面端与 Web 端通用。
>
> A Luna-Chat inspired theme plugin for the DeepSeek Harness desktop and web shells.

**换肤部分只改样式，不改功能。** 插件不注册工具、不读写会话、不改用户设置；停用后界面完全恢复原样。

0.3.0 起包内附一个**可选**的余额挂件（右下角露娜立绘，气泡里是 DeepSeek 账户余额）。
它会读取你的 `DEEPSEEK_API_KEY` 并向 `api.deepseek.com` 查询余额 —— 不想要就按
[关闭余额挂件](#关闭余额挂件) 关掉，插件即回到纯换肤。

0.4.0 起还多了三样：**设置弹窗的插画背景**、主按钮与普通按钮的**第二档皮肤**
（连同设置里的下拉）、以及输入框下方那个**「内存占用」徽标**。它们都是只读的界面装饰 ——
徽标只在本机读内存，不外发任何数据、不写任何文件。

---

## 效果

深靛蓝底 + 半透明紫玻璃面板 + 樱花粉第二强调色 + 实底 CTA（暗色金、亮色樱花），外加一张铺满全屏的壁纸。

| 角色 | 暗色 | 亮色 |
|---|---|---|
| 应用底 / 对话区 | `rgba(26,26,46,.23)` | `rgba(247,245,252,.16)` |
| 侧栏 | `rgba(15,15,35,.25)` | `rgba(242,190,210,.18)` 淡樱花粉 |
| 抬升面（卡片 / 弹窗） | `#16213e` / `#1e1e3a` / `#262648` | `#ffffff` / `#f6f3fd` / `#efeaf9` |
| 菜单玻璃 | `rgba(41,32,78,.78)` + `blur(14px)` | `rgba(255,255,255,.80)` + `blur(14px)` |
| 正文 / 次级 / 三级 | `#e8e8ed` / `#dbdbe9` / `#cfcfdd` | `#221c36` / `#332d47` / `#544c6e` |
| 链接 | 樱花 `#ffced8` | 深酒红 `#7d0a36` |

| 普通按钮 / 下拉（第二档） | 半透紫底 `rgba(74,58,122,.5)` + 暗金边 `#b69e42` + 金字 `#ffd700` | 白底 `#ffffff` + 淡樱边 `#ef90ab` + 蓝紫字 `#4a3a7a` |

除配色外还调整了：壁纸层与遮罩、设置弹窗的插画背景、普通按钮与下拉的第二档皮肤、
选区颜色、Markdown 标题的樱花竖线、分隔线渐变、引用块、列表符号，以及对话区右缘
**轮次导航**（快速跳转刻度）的樱花配色。

> 轮次导航只有会话达到 2 轮以上时才出现，这是 DSH 组件自身的行为。

## 普通按钮与下拉

主按钮之外的控制统一用 Luna-Chat 的**第二档**皮肤：弹窗里的「取消」、设置里的「打开配置文件」、
设置弹窗里的下拉选择器、输入框下方的读数胶囊，暗色是半透紫底 + 暗金边 + 金字，亮色是白底 +
淡樱边 + 蓝紫字，一律大圆角。

- 点击输入框下方那三个读数（模型步数 / 输出速度 / 缓存命中率）与上下文圆环，会向上弹出明细面板，
  面板用的是同一档皮肤。
- **保持 DSH 原样**的几类：主题外观的三个色块（它们本身就是展示配色的色板）、设置左侧的导航行、
  Agent 预设卡片、以及纯图标按钮（关闭 / 缩放 / 清空搜索）—— 给它们套上带边框的胶囊会破坏其形状。

## 设置弹窗的背景图

设置弹窗用一张《近月少女的礼仪》插画作背景，遮罩强度与主界面壁纸完全一致，所以两处看起来是
同一个景深。它和壁纸一样**内联**在 `client.js` 里（常量 `SETTINGS_DATA_URI`），入包前已经烤入
4px 模糊。想换图或去掉，见 [替换壁纸与背景图](#替换壁纸与背景图)。

## 内存占用徽标

输入框下方那一行的最右边多一个「内存占用：xx%」胶囊，样式与旁边的读数一致：

- **点击**（不是悬停）展开明细：第一行是 `DSH 占用 / 电脑已用 / 电脑总量`，
  下面按进程组列出本应用的占用。
- 数据全部来自本机：系统内存读 Node 的 `os.totalmem()` / `os.freemem()`；本应用的进程组在
  Windows 上用系统自带的 `tasklist` 按可执行文件名统计，其他平台只报运行 DSH 的那个进程。
- 徽标每 5 秒刷新，明细面板打开时每 3 秒刷新。**纯只读，不发送任何数据。**
- 若插件被换回不含这两条路由的旧版本，徽标会自己隐藏，不会在页面上留一个死胶囊。

## 安装

需要 DSH CLI。把插件作为 bundle 装进目标 profile：

```sh
# 从 GitHub 仓库直接装
dsh plugin --profile desktop add github:shinku-xuan/dsh-luna-theme

# 或从本地目录 / 打包产物
dsh plugin --profile desktop add ./dsh-luna-theme
dsh plugin --profile desktop add ./dsh-luna-theme-0.4.2.tgz
```

装完**重启桌面端**（或 DSH Web 进程）生效。

> 换肤部分改完不用重启就能看到（客户端 bundle 是热重载的）；但**余额挂件的四条路由**与
> **内存徽标那两条路由**都是在启动时注册的，**要重启才生效**。

## 卸载

```sh
dsh plugin --profile desktop remove dsh-luna-theme
```

移除后 token 层与样式表都会自动撤回，界面回到 DSH 原样。

## 余额挂件

右下角一张露娜立绘，气泡里是 DeepSeek 账户余额：

- **余额**取自 `https://api.deepseek.com/user/balance`，密钥是 profile 里配置的 `DEEPSEEK_API_KEY`
  （未配置时气泡显示提示）；宿主侧有 25 秒缓存与请求去重，60 秒自动刷新，**点击立刻刷新**。
- **拖拽**：拖到左右各四分之一区域自动吸附该边，吸附在左侧时整只（含文字）水平翻转。
- **大小**：悬停后右上角出现 `-` / `+`，缩放会记到插件目录里。
- 瞬时网络失败时继续显示上一次的余额，不会闪错误。

### 关闭余额挂件

在 profile 的 `cordis.patch.yml` 里加一条，然后重启 DSH：

```yaml
- id: luna-balance-widget
  disabled: true
```

删掉这条即恢复。挂件与换肤是**两条独立的行**：关掉挂件不影响换肤；但反过来关掉整个插件
（即换肤那一行）会连挂件一起关掉 —— 页面脚本是由换肤的客户端 bundle 加载的。

> 挂件大小记在插件自己的目录里，**重装插件会重置为默认大小**。

## 兼容性

- 面向 DSH 桌面端 / Web 端（`dsh.client.platform: web`）。
- 依赖 DSH 的 `--dsw-*` 别名 token（当前覆盖 87 个）。**DSH 大版本升级后 token 名可能变化**，
  若发现某些界面不再跟随主题，通常就是这个原因。
- 不修改任何布局：内外边距、控件尺寸、字号一律不动。唯一例外是 Markdown 分隔线由 `0.5px`
  改为 `1px`，因为发丝线承载不了樱花渐变。
- 普通按钮与下拉的皮肤是按 DSH 组件的**类名局部名**（如 `_outline_`、`_selector`）匹配的，
  不含内容哈希。DSH 若给这些控件改名，对应的那几条规则会**静默失效、回退成原样**，
  不会影响其余部分 —— 升级后若发现某个下拉没跟着主题走，原因通常在此。

## 替换壁纸与背景图

两张图都是**内联在 `client.js` 里的 data URI**（不写成外链，是为了让加载链路上任何一环都不能
静默失败）：主界面壁纸是 `WALLPAPER_DATA_URI`（`assets/wallpaper.webp`，建议 1920×1080），
设置弹窗背景是 `SETTINGS_DATA_URI`（`assets/luna-settings.webp`，1024×1024）。要换成自己的图，需要：

1. 准备图片并转成 WebP（壁纸 ~40 KB 量级，背景图 ~30 KB 量级），想保留主题的柔和感可以先用
   图像工具烤入 4px 高斯模糊；
2. base64 编码后替换 `client.js` 里对应常量的值；
3. 重启 DSH（客户端 bundle 会热重载，但重启最稳）。

想去掉壁纸只保留配色，把 `--luna-scrim` 的 alpha 调到 `1` 即可得到纯色底；想单独去掉设置背景，
把那条 `body [data-shortcut-modal='settings']` 规则删掉即可回到原来的面板底色。
