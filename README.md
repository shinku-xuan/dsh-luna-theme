# dsh-luna-theme

为 DSH 桌面端和 Web 客户端提供 [Luna-Chat](https://github.com/shinku-xuan/Luna-Chat) 风格的浅色与深色主题，并随包提供露娜余额挂件、朝日桌宠和游戏主界面开屏。

## 安装与组件开关

这是 DSH bundle：安装到目标 profile 后，重启应用加载主题与组件。插件包版本为 **0.12.0**。

| 行 id | 功能 | 包入口 |
| --- | --- | --- |
| `dsh-luna-theme` | 配色、材质、背景动画和内存徽标 | `dsh-luna-theme` |
| `luna-balance-widget` | 露娜余额挂件 | `dsh-luna-theme/widget` |
| `luna-pet` | 朝日桌宠与聊天 | `dsh-luna-theme/pet` |
| `luna-opening` | 启动页皮肤、镜头拉远开屏与语音 | `dsh-luna-theme/opening` |

三个组件可单独停用。在 profile 的 `cordis.patch.yml` 中按行 id 设置 `disabled: true`，例如：

```yaml
- id: luna-opening
  disabled: true
```

调整 Host 组件配置后重启应用。停用主题主行会撤回主题样式、背景动画和它加载的组件页面脚本。开屏随主题提供，无需另装开屏插件。

## 主题外观

浅色模式使用樱花粉、白色玻璃面板和蓝紫色次要按钮；深色模式使用紫色玻璃面板和金色强调。设置面板、菜单、输入框读数、Markdown 内容与对话轮次导航使用相应配色。模式切换带柔和渐变，窗口的最小化、最大化和关闭按钮直接跟随当前模式。

壁纸缓慢移动与缩放，十八片樱花在文字与面板下方飘落，不接收鼠标输入。页面进入后台时暂停背景动画；系统启用“减少动态效果”时停用背景运动、粒子和模式渐变。背景是 CSS 动画，角色表情与姿势保持静态。

输入框下方的内存徽标显示电脑内存使用率；点击后查看系统总量、已用量和 DSH 进程占用。Windows 按当前可执行文件名汇总进程；其他平台或读取失败时仅显示 Host 进程，因此同名的其他进程可能计入 Windows 的汇总。

## 露娜余额挂件

头像为透明背景、银白长发、红色胶囊眼的极简露娜形象，保留独立白色余额框并水平镜像显示。点击人物刷新余额，拖拽可移动并吸附到屏幕左右边缘。

鼠标靠近挂件和按钮区域时，收起、放大与缩小按钮显示；移开后隐藏。键盘聚焦时显示操作，触屏上保持显示。点击收起按钮后挂件移到屏幕外，靠近边缘可找到展开按钮，再次点击恢复位置和尺寸。操作与余额状态支持中英文。

余额请求使用 DSH 配置的 DeepSeek 凭据，查询官方余额接口。无凭据或查询失败时白框显示失败状态，可点击重试；密钥不会发给页面。尺寸保存在包目录的 `.dshw-size.json`，可读取 profile 根的旧尺寸文件；替换安装包可能丢失包内的尺寸记忆。收起状态仅在当前页面保留。

## 朝日桌宠

朝日在窗口底部活动，支持拖拽、抛掷、落地反弹、点击反应、打盹以及任务状态联动。十二种姿态各有一张八帧动作图集，并保留静态姿态作为回退；资源解码前保留当前画面，不显示空帧。

右键菜单提供对话、切换模型、清空上下文、调整尺寸、回到角落、原地不动和睡一会儿。回家时加快位移，步态节奏保持正常；原地不动只暂停自主漫游，拖拽、抛掷和回家仍可使用。位置、尺寸、打盹与移动偏好保存在浏览器 localStorage。

桌宠聊天使用 DSH 已配置的模型，会消耗对应模型额度。回复以流式文字显示，发送时提示正在思考；输入框与模型列表锚定在朝日手边。点击页面其他位置收起聊天，点输入框和菜单不会误收起。关闭窗口或清空上下文会清除这一轮聊天记录。

聊天路由使用应用的请求鉴权，鉴权服务缺席时拒绝请求。人格提示词随包提供于 `persona/asahi-chat.md`。这组聊天不写入 DSH Session，主题也不注册模型工具。

## 开屏动画

应用加载后，视点从中央近景逐渐拉远，外侧角色从画面外进入并保持前后遮挡；镜头就位后，三层原版 Logo 依次展开。浅色模式使用 `Back_1.png`，深色模式使用 `Back_2.png`。画面等比例铺满窗口并居中裁切超出部分，窗口比例变化不会留下两侧黑边。

默认入场与停留共 7.6 秒，随后用 1.4 秒渐黑。完全黑屏并绘制后才播放 `lun_sp06.wav`，等待语音实际播放结束，再退出开屏。正常播放总时长约 11.6 秒，另加素材读取时间。

点击画面或按 Esc 可跳过，语音期间同样有效。浏览器阻止自动播放时，全黑画面显示“播放语音”；图片或音频失败时提供重试，也可点击空白画面跳过。播放与重试按钮不会同时触发跳过。系统启用减少动态效果时直接显示完成构图，停留与渐黑缩短，仍等待语音结束。

开屏期间应用内容不可交互；退出或卸载会停止语音、撤回遮罩并恢复原有焦点和交互状态。开屏只读取挂载时的主题，不修改模式偏好。
